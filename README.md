# 📊 Pandas Data Analysis Project

This project is part of my learning journey in data analysis using Python and the Pandas library.

## 📁 Project Overview
In this project, I created and manipulated a DataFrame to practice essential data analysis skills.

## 🛠️ Tasks Performed
- Created a DataFrame with 15 rows and 3 columns:
  - Level
  - Course Name
  - Major
- Handled missing values (NaN)
- Converted data types (Level to float)
- Used `describe()` to explore the dataset
- Displayed the first 4 rows of the data
- Removed rows with all null values

## 💡 Skills Gained
- Data cleaning
- Data manipulation using Pandas
- Handling missing data
- Data exploration

- Python
- Pandas
- Jupyter Notebook
